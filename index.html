Formularios en HTML

Formulario de contacto

campos de textos básicos: simple, con placeholder, obligatorio(equired),de solo lectura (readonly), deshabilitado(disabled)






Contacto

campos especializados para datos de contacto: contraseña, correo electronico, teléfono y URL, cada uno con su propio teclado y validación en el navegador.





Númericos

campos para valores numéricos: un número con límites(min/max) y un deslizador (range), para elegir un valor dentro de un rango.



Fecha y hora

Selectores nativos de fecha y hora: fecha, hora, fecha y hora combinadas, mes y semana del año.






Selección

campos de selección: elegir un color, marcar una casilla elegir una opción de un grupo de radios y subir un archivo.




Listas Desplegables (select)

Listas desplegables con el elemento select: una opción simple, una con valor preseleccionado(selected), una agrupada (optgroup), una con múltiples selecciones (multiple) y una deshabilitada (disabled)
